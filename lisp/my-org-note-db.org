#+title: Note commands

Package interfaces and queries: [[file:~/projects/org-note-graph/README.org][Org Note DB]].

Under =C-c n=: =f= finds, =i= inserts links, =q= opens a query view,
=b/l= show backward/forward links, =g= searches content, =h= finds broken links,
and =r= refreshes. Find/insert capture new titles; prefix insert selects a
subheading and assigns its ID. =C= explicitly assigns an ID.

=e= extracts the current subtree into a new file note, leaving nothing behind.
=m= moves the whole file beneath another note or heading, then trashes the old
file. Both commands save their moves and preserve IDs. File/search links and
inherited settings need review; task headings use native =org-refile=.

=s= selects a destination, name and matching location; prefix inserts its link.
=t/a= edit =GRAPH_TAGS=/=ALIASES=; prefix removes a value. These feed =Tags= and
=Aliases=. Only =Aliases= supplies alternative names for note search.

In Org, =M-.= looks up names tagged =Definition= in =Tags=; =C-u M-.= prompts
with completion. Emphasized text or a selected region supplies multiword names.
=M-,= returns through Xref's history.

=d= sets up a Scanner, Capture Target or Link pairs list; detailed settings remain properties.
=T= captures at a target; presets receive the current note unless it owns the
target. A prefix makes the preset ask for all input.
=c= opens ordinary Org capture. Project README files are discovered through
file links in Projects. Popup placement and keybindings are configured here.

The personal pair-list extension registers =Dualismen=. =C-c n T= → =Dualismen=
adds two note links and leaves room for an explanation. From another note, only
the second participant is requested; from the list or with a prefix, both are.
=M-x my/org-note-db-related= shows related notes through a selected relation table.
Pairs are declared by =PAIR_TARGET=, independently of the selected =CAPTURE= preset.

Use =C-.= on an =id:= link or a find/insert candidate. =SPC= toggles an Embark
selection; =A= acts on selected candidates. With no marks, it uses the ID links
in the active region or current Org list (including sublists), or all filtered
candidates in a picker. Thus =C-. A t= tags a whole list without marking each link.
In query views, =m= toggles a mark, =a= acts on one result, and =A= acts on marked
results, the active region or all results. =t= adds a graph tag; =x= runs an Emacs command or named macro in
each note. =RET= follows the selected location; edits act on its owning node.
Heading nodes are narrowed to
their subtree. Edits remain unsaved. Refreshing a query view clears its marks.
Add list actions through =my/org-note-db-action-map=
and =embark-multitarget-actions=; =my/org-note-db-action-nodes= resolves their keys,
and =my/org-note-db-map-notes= runs a function in each note's buffer.
