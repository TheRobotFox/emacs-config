#+title: Personal graph commands

The indexing modules live in [[file:~/projects/org-note-graph/README.org][org-note-graph]]. Personal commands and the symbolic
query language live here; popup and project integration remain in this config.

Under =C-c n=: =d= declares a Scanner or Capture Target at the current heading
(or file preamble). =t= adds a graph tag; =a= adds an alias. Prefix either to remove
an entry. =T= captures at a declared destination;
=c= opens ordinary Org capture. =f= finds notes, with a prefix selecting through
a query. =i= inserts a note link; with a prefix it offers subheadings and assigns
the selected heading an ID if needed. Find and insert can capture a new title.
=C= explicitly assigns an ID. Use native Org commands for reorganization.

=s= selects a destination, then an indexed name (such as a tag), then a location
if several match; with a prefix it inserts a link.
=q= reads a graph query, =g= searches node content, =b= and =l= show references
into and out of the current node, =h= reports unresolved links, and =r= refreshes.
Setup leaves edits unsaved. Projects are discovered through ordinary file links.

The personal module registers =Tags= and =Aliases= and their property bindings.
Graph tags and aliases append to =GRAPH_TAGS= and =ALIASES=, quoting names as needed;
they feed =Tags= and =Aliases= using the same schema. Scanner setup selects content and asks for a missing target;
capture setup selects the native capture type. Edit properties for further settings.
=SCAN_TARGET= is required; =Tags(TagX)= classifies each match as =TagX=.
Nested scanner declarations delimit their scopes; =SCAN: off= excludes one.
=CAPTURE= accepts =entry=, =plain= or =item=; =CAPTURE_TARGET= defaults to =Capture=.
=C-c n T= prefills item capture with the current node's link when available. Finish or
cancel with ordinary Org capture commands. Membership is the ordinary link.

Queries use =->= / =<-= for references, =-*>= / =<*-= for reachability
(including the starting nodes), and =?= for a path's result. Combine sets
with =&=, =|=, =\= and =!= (complement within the current scope; globally, all nodes).
=@= binds tightest, then =!=, paths, =&= / =\=, then =|=; parentheses group.
=.= means the current node, =*= all nodes. Bare names search titles/aliases;
quoted names match exactly, ignoring case. Use =M-i= to insert a precise link.
Query results retain locations. Arrows use their owning nodes and return the
reached nodes; set operations compare exact file positions. =*@Table= selects all
locations in a destination. =(!term)@Table= excludes matches within that destination.
=label@Table= searches labels and named locations contributed to that scope; =(flow | cut)@Table=
matches either label, while =&= requires both. Tables are ordinary node-set
expressions or registered destination names; group compound expressions.
Each path has one hole. Semicolon-separated clauses can define =?x=;
repeated definitions intersect, and =$x= reads the set. Dependencies must be
acyclic; the final clause returns the result.
With =A -$x> ?=, only intermediate nodes must belong to =$x=; direct links
and the starting nodes still qualify. =-Name>= uses a title/alias search as
the intermediate set. Bind more complex sets with a named hole first.

In query results: =e= edits, =g= refreshes, =f= selects a node to visit, and
=i= selects a link to insert at the original writing position. Direct commands
=my/org-note-graph-query-find= and =my/org-note-graph-query-insert= share the
same query input and history. Selection still permits capturing a new title.
=query:= links open expressions in this popup; =.= refers to the containing node.
Use Org's insert-link command to create one, or store a link from a query view.
